Модель (LLM)

Через модель идут разбор постов, оценка вакансий и письма. Основной провайдер работает всегда; запасной включается сам, если основной закрыт (ключ, оплата, верификация), и система раз в 15 минут проверяет, не вернулся ли основной. Ключи только записываются: страница их не показывает. Пустое поле ключа при сохранении — «оставить как есть».

Провайдеры

Задачи

Какой провайдер делает каждую задачу. «нет» — основной провайдер. Разбор и оценка массовые — им нужна дешёвая модель; письма — лучший русский текст. Перед оценкой из резюме убираются имя и контакты.

DeepSeek

platform.deepseek.com → API Keys. Самый дешёвый для массовых задач, есть скидка на повторяющееся начало запроса (резюме в оценке). Данные уходят на серверы в Китае.

Anthropic (Claude)

console.anthropic.com → API Keys.

OpenAI-совместимый API

YandexGPT, DeepSeek, OpenAI и другие. Заготовки заполнят адрес и модели — останется вписать ключ.

GigaChat (Сбер)

developers.sber.ru → проект GigaChat API → «Авторизационные данные».

Экономия

У Claude резюме в промпте кэшируются, и оценка вакансии стоит копейки. У YandexGPT и GigaChat кэша нет: каждая вакансия оплачивается с обоими резюме целиком, и сильная модель на сотнях вакансий в день обходится дорого. Лёгкая модель для оценки дешевле в разы, письма при этом пишет сильная.

Прокси

hh.ru не отдаёт страницы адресу этого сервера, поэтому поиск вакансий, автоотклик и учёт ответов идут через прокси. Трафик платный: когда пакет кончается, прокси не отказывает, а молчит, и встаёт всё, что связано с hh.

Отклики по почте

Вакансии, где единственный контакт — почта рекрутёра: письмо под вакансию и PDF резюме профиля уходят с вашего ящика. Режим «с подтверждением» присылает письмо в телеграм с кнопкой «📧 Отправить»; «авто» отправляет само в пределах лимитов. Нужен пароль приложения, не обычный пароль: Яндекс — id.yandex.ru → Безопасность → Пароли приложений (тип «Почта»); Gmail — myaccount.google.com → Безопасность → Пароли приложений; Mail.ru — Настройки → Безопасность → Пароли для внешних приложений.
